# Desktop Notebook

> ReadMe内容用ai重新整合，可自行辨别

一个纯本地的桌面笔记工具。笔记就是磁盘上的 Markdown 文件，便签就是 `.txt` 文本，不联网、不登录、不上传，所有内容都能直接用别的软件打开。

![Electron](https://img.shields.io/badge/Electron-41-47848F?logo=electron&logoColor=white) ![Vue](https://img.shields.io/badge/Vue-3-42b883?logo=vuedotjs&logoColor=white) ![Vite](https://img.shields.io/badge/Vite-8-646cff?logo=vite&logoColor=white)

## 功能

### 笔记

- Markdown 编辑器，支持标题、列表、引用、表格、代码块、任务列表、图片
- 一篇笔记一个文件夹，正文是 `.md`、元信息是 `.json`，可以直接丢进任何 Git 仓库
- 多标签页并行编辑，每篇笔记的标签 0~3 个（也可以一个都不加）
- 实时字数统计（中文按字、英文按单词，代码块不计入）
- 一键「阅读模式」把当前笔记排成适合阅读的文章视图，再点一次回到编辑
- 专注模式：隐藏侧栏、标签栏和标签页，只留正文

### 便签

- 独立的桌面小窗口：无边框、置顶、不占任务栏，可自由拖动和缩放
- 边打字边存，没有「保存」按钮
- 颜色比普通笔记卡片更醒目，列表里带「便签」角标

### 知识网

- 一块可以无限平移的画布，把笔记之间的关系画出来
- 滚轮直接缩放（40%~200%），顶栏有「适应视图」一键收全
- 右键新建「知识节点」（关联某篇笔记）或「注释」（直接写文字）
- 从节点两侧的加号拖到另一个节点即可连线，鼠标移到线上会出现 × 删除连接
- 点笔记节点直接跳回编辑页；每一次操作都立刻写盘

### 查找与整理

- 全文搜索：标题和正文一起搜，关键词高亮，可按「全部 / 笔记 / 便签」筛选
- 回收站：删除先进回收站，可以单条还原、彻底删除或一键清空，笔记和便签在同一个页面
- 标签管理：给标签设 8 种颜色之一、置顶、重命名、删除（重命名到已有标签会自动合并）
- 导入：批量选 `.md / .markdown / .txt` 文件，或直接导入整个文件夹
- 导出：任意笔记、便签导出为单个文件
- 备份：把配置、笔记、便签、知识网整体复制到一个带时间戳的新文件夹

### 桌面体验

- 关闭窗口默认收进系统托盘继续待命（可在设置里改成直接退出）
- 托盘菜单：显示窗口、新建笔记、新建便签、退出，菜单里直接显示当前快捷键
- 全局快捷键，窗口藏起来时也能用：默认 `Ctrl+Shift+N` 新建笔记、`Ctrl+Shift+S` 新建便签，可在设置里点一下按键框直接录制修改
- 浅色 / 深色双主题，切换立刻生效并同步到所有窗口
- 平面（Flat）风格：无阴影、无发光，靠描边和色块区分层级

## 开发

需要 Node.js `^20.19.0` 或 `>=22.12.0`。

```bash
npm install
npm run electron:dev     # 开发模式（Vite 热更新 + Electron）
npm run electron:build   # 打包，产物在 dist_electron/<版本号>/<架构>/
```

打包会同时产出 64 位和 32 位两个 Windows 安装包。
